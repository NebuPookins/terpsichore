# Terpsichore — DDR Training Log

A training log app for Dance Dance Revolution. Built with React, Vite, and Tailwind CSS. Data is stored in your browser (localStorage) with export/restore available in Settings.

## Setup

```bash
bun install
```

## Commands

| Command | Description |
|---|---|
| `bun run dev` | Start the Vite dev server (localhost:5173) |
| `bun run build` | Build for production into `dist/` |
| `bun run preview` | Preview the production build locally |

## Stack

- **Vite** — build tool and dev server
- **React 19** — UI framework
- **Tailwind CSS 4** — utility-first styling
- **Recharts** — session history charts
- **Lucide React** — icons
